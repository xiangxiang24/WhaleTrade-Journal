# Emotion emoji sources

Images are the "Smilies" set from **Animated Fluent Emojis** by Tarikul Islam Anik
(https://github.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis), based on Microsoft Fluent Emoji (MIT License).
Browse: https://animated-fluent-emoji.vercel.app

| File | Source image | Mood code |
|---|---|---|
| overjoyed.png | Grinning Face with Big Eyes | `overjoyed` |
| happy.png | Smiling Face with Smiling Eyes | `happy` |
| neutral.png | Face with Diagonal Mouth | `neutral` |
| worried.png | Worried Face | `worried` |
| sad.png | Loudly Crying Face | `sad` |

The originals are animated 256 x 256 PNGs (1-3 MB each). They were downscaled to 128 x 128 (first frame, static)
because they are shown at 16-40 px. Files are bundled with the app so it works offline (do not hotlink).
