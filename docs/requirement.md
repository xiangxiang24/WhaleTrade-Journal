# Trading Journal — Requirements (Iteration 2)

แอปสำหรับนักลงทุนระยะยาว เขียนด้วยเทคโนโลยีเว็บ แล้วหุ้มเป็นแอปบน macOS ใช้งานส่วนตัว (ไม่ขึ้น App Store) แบ่งเป็น 2 ฝั่งที่ไม่เกี่ยวข้องกัน
- ฝั่ง Journal: โน้ตเหตุผลการลงทุน + อารมณ์ + เตือน/ปฏิทิน/task
- ฝั่ง Port: พอร์ต, Goal, transaction, เครื่องคำนวณเงินเป้าหมาย
โน้ตไม่ผูกกับ transaction และ transaction ไม่ผูกกับโน้ต

## FEATURE 1: JOURNAL (โน้ตเหตุผลการลงทุน + อารมณ์)

**หน้า: หน้ารวมบันทึก (My Journals / Dashboard หน้าแรก)**
- ไทม์ไลน์โน้ตทั้งหมด เรียงจากใหม่ไปเก่า
- แต่ละรายการแสดง: แถบสีตามอารมณ์, วันที่, บรรทัดแรกของโน้ต
- กรองตามอารมณ์ได้ เช่น "ดูทุกอย่างที่ฉันเขียนตอนกังวล"
- ปุ่ม "เขียนโน้ตใหม่" อยู่ในตำแหน่งที่กดง่ายตลอดเวลา
* ปุ่ม Export โน้ตเป็น CSV (ดู Feature 5)
* Empty state: ถ้ายังไม่มีโน้ต แสดงข้อความชวนให้เขียนโน้ตแรก

**หน้า: เขียน / ดู / แก้โน้ต**
- เลือกประเภทโน้ตตอนสร้าง: "เหตุผลที่ซื้อ" หรือ "โน้ตทั่วไป" (ใช้หน้าจอเดียวกัน)
* ทุกโน้ตมี: ช่องเลือกหุ้น/กองทุน (เลือกจากรายการ ดู Feature 6) และช่องเนื้อหาเขียนอิสระ
* ถ้าเลือกประเภท "เหตุผลที่ซื้อ" จะมีช่องเสริม 3 ช่อง (ไม่บังคับกรอก)
   - "อะไรที่จะทำให้ฉันเปลี่ยนใจ?"
   - "ฉันจะวัดผลว่าการลงทุนนี้ยังไปได้ดีอยู่ด้วยอะไร?" เช่น บริษัทยังจ่ายปันผลสม่ำเสมอ ไม่ถูกลดปันผล
   - กฎการขาย (Sell rules) เช่น "ฉันจะขายก็ต่อเมื่อบริษัทลดปันผล โมเดลธุรกิจพัง หรือเจอที่ลงทุนที่ดีกว่าชัดเจน" เขียนตอนใจเย็น ไว้เตือนตัวเองตอนตื่นตระหนก
- โน้ตเรื่องการขาย (เช่น "วันนี้ขายเพราะ...") จดเป็นโน้ตทั่วไป ไม่มีหน้าพิเศษ
- แก้ไขและลบโน้ตได้ การลบต้องถามยืนยันก่อน

**ส่วนประกอบ: แท็กอารมณ์ (อยู่ในหน้าเขียน/ดู/แก้โน้ต)**
- ทุกโน้ตเลือกอารมณ์ได้ 1 อย่าง เป็นอิโมจิพร้อมคำอธิบาย ผู้ใช้ไม่พิมพ์เอง เพื่อให้โฟกัสที่การจดโน้ต
- รายการอารมณ์และสี
   - 😆 Overjoyed (มีความสุขล้นหลาม) = เขียวเข้ม
   - 🙂 Happy (ดีใจ) = เขียวอ่อน
   * 😐 Neutral (เฉยๆ) = เทา
   * 😟 Anxious (กังวล) = ส้ม
   * 😢 Sad (โศกเศร้า) = น้ำเงิน
- เปิดโน้ตแล้วกดอิโมจิได้เลย ไม่ต้องเข้าหน้าแก้ไข
* เปลี่ยนอิโมจิใหม่ได้ทุกเมื่อ
* ยังไม่เลือกอารมณ์ = จุดสีเทาอ่อน ("ยังไม่ระบุ")
* สีต้องแยกออกจากกันได้แม้ผู้ใช้ตาบอดสี (แสดงอิโมจิคู่กับสีเสมอ)
* ระบบเก็บเวลาที่เปลี่ยนอารมณ์ล่าสุดไว้เบื้องหลัง ไม่แสดงในหน้าจอ

## FEATURE 2: PORT (พอร์ตและ Transaction)
ฟีเจอร์นี้ไม่เกี่ยวกับ Journal ทั้งหมด ไม่มีโน้ต ไม่มีอารมณ์

**หน้า: รายการพอร์ต (Portfolio)**
- สร้างได้หลายพอร์ต ตั้งชื่อได้ ใส่คำอธิบายสั้นๆ ได้
* แก้ชื่อได้
* แต่ละการ์ดพอร์ตแสดงชื่อ คำอธิบาย และความคืบหน้า Goal กดการ์ดเพื่อเข้าหน้าพอร์ต
* ลบพอร์ตแบบ Soft delete พอร์ตที่ลบไปอยู่ในหน้าถังขยะ
* Empty state: ยังไม่มีพอร์ต

**หน้า: ถังขยะ (Trash)**
- แสดงพอร์ตที่ถูกลบ กู้คืนได้
* ลบถาวรได้เฉพาะเมื่อผู้ใช้เข้ามากดลบเอง (ไม่ลบอัตโนมัติ) และต้องถามยืนยันก่อน
* transaction ในพอร์ตไม่หายไปตอน soft delete
* พอร์ตในถังขยะไม่แสดงในรายการพอร์ต ไม่ถูกเลือกในเครื่องคำนวณ และไม่อยู่ใน CSV
* Empty state: ถังขยะว่าง

**หน้า: หน้าพอร์ต (Goal + สรุป + Port log)**
การ์ด Goal
- ตั้ง Goal เป็นจำนวนเงินได้ เช่น 2,000,000 บาท แก้ได้
* progress bar แสดงความคืบหน้า เช่น "800,000 / 2,000,000 (40%)"
* ยอดในแถบ = เงินต้นเริ่มต้น + DCA ที่บันทึกทั้งหมด (ดึงจาก transaction ของพอร์ตนั้น)
* ใต้แถบมีข้อความ "คำนวณจากรายการที่บันทึก ไม่ใช่มูลค่าตลาด"
* เมื่อถึง 100% สถานะเปลี่ยนเป็น "ถึงเป้าแล้ว"
* เพิ่ม/แก้/ลบ transaction แล้วยอดในแถบอัปเดตตามทันที

**การ์ดสรุป**
- Holdings: จำนวนหุ้น/กองทุนที่อยู่ในพอร์ต พร้อมป้ายสัญลักษณ์ของแต่ละตัว
- Total Recorded DCA: ผลรวมที่ลงทุนตามรายการที่บันทึก

**Port log (ตาราง transaction ของพอร์ต อยู่ในหน้าเดียวกัน)**
- คอลัมน์: วันที่, ประเภท, หุ้น/กองทุน, ราคาต่อหน่วย, จำนวนหน่วย, ค่าธรรมเนียม, จำนวนเงิน, ปุ่มแก้ไข/ลบ
* แบ่ง section เป็นรายเดือน เช่น "ตุลาคม 2026" เรียงใหม่ไปเก่า
- ช่องค้นหา: ค้นตามชื่อหุ้น/กองทุน เช่น Apple, SCB, TISCO
- ตัวกรอง: เลือกเฉพาะเดือน
- แก้ไขและลบ transaction ได้
- ปุ่ม "Add Transaction" และปุ่ม "Export CSV" อยู่ที่หัวหน้า
- Empty state: พอร์ตใหม่ที่ยังไม่มี transaction
- ข้อมูลหุ้นในพอร์ตนี้ส่งต่อให้เครื่องคำนวณ (Feature 3) เลือกใช้ได้

**ส่วนประกอบ: เพิ่ม / แก้ transaction**
- ประเภท: ซื้อ / ขาย / ปันผล (ปันผลเป็นแค่ transaction ประเภทหนึ่ง ไม่มีหน้าบันทึกปันผลแยก)
- วันที่
- หุ้น/กองทุน (เลือกจากรายการ ดู Feature 6)
- ประเภทซื้อ/ขาย: ราคาต่อหน่วย, จำนวนหน่วย, ค่าธรรมเนียม
- ประเภทปันผล: จำนวนเงิน
- ช่องที่ไม่จำเป็นไม่บังคับกรอก ฟอร์มเรียบง่ายที่สุด
- ถ้าผู้ใช้นำปันผลไปลงทุนต่อ (DRIP) ต้องบันทึกเองเป็น transaction ซื้อ แอปไม่ทำให้อัตโนมัติ

## FEATURE 3: TARGET AMOUNT (คำนวณเงินเป้าหมาย)
เป็นหน้าเดียว เลื่อนลงได้ มี 3 section เรียงต่อกัน (ไม่มีหน้าแยก)

**Section 1: ฟอร์มคำนวณ**
- เลือกพอร์ตที่จะนำมาคำนวณ หรือไม่เลือกพอร์ตแล้วกรอกเองทั้งหมดก็ได้ (Optional)
- ถ้าเลือกพอร์ต ระบบดึงรายการหุ้นในพอร์ตมาแสดง ผู้ใช้ใส่ปันผลของแต่ละตัวเป็น % ต่อปี
- ถ้ากรอกเอง ผู้ใช้เลือกหุ้น/กองทุนจากรายการ (Feature 6) แล้วใส่ปันผล % ต่อปี
- เงินต้น (บาท)
• DCA ต่อเดือน (บาท)
- ระยะเวลา (ปี)
- แบ่งเฟสได้หลายเฟส เช่น เฟส 1 = 2 ปีแรก DCA เดือนละ X บาท, เฟส 2 = DCA เดือนละ X+Y บาท
- ไม่มีการสมมติการเติบโตของราคาหุ้น และไม่ดึงราคา real-time
- ปุ่ม "Calculate" (หลังคำนวณแล้วเปลี่ยนเป็น "Recalculate")

**Section 2: ผลลัพธ์ (แสดงต่อด้านล่างหลังกดคำนวณ)**
- เงินปลายทางที่คาดว่าจะได้เมื่อครบระยะเวลา
- รายละเอียดการคำนวณ: เงินต้น, DCA สะสมของแต่ละเฟส, ปันผลที่คาดว่าจะได้
- ข้อความ "นี่คือการประมาณการ ไม่ใช่การคาดการณ์ผลตอบแทนจริง"
- ปุ่มบันทึกแผน (ตั้งชื่อแผน)
- ปุ่ม Export เป็น PDF หรือรูปภาพ ที่ดูสวยพร้อมนำไปใช้ได้ (ไม่มี export CSV)
- ก่อนกดคำนวณ section นี้แสดงข้อความว่า "ผลประมาณการจะแสดงที่นี่หลังคำนวณ"

**Page: หน้าแผนที่บันทึกไว้ (Saved Plans)**
- มีหน้าแยกที่รวม saved plan ทุกอันไว้ 
- รายการแผนที่บันทึก แต่ละแผนมีชื่อ เงินปลายทาง ระยะเวลา แหล่งที่มา (จากพอร์ตหรือกรอกเอง) และวันที่บันทึก
- เปิดดู (โหลดขึ้นไปในฟอร์มด้านบนพร้อมผลลัพธ์), แก้ไข, ลบ (ถามยืนยันก่อน)
- Empty state: ยังไม่มีแผนที่บันทึก

## FEATURE 4: เตือน ปฏิทิน และ TASK (เมนู Reminders)

การเตือนเป็น notification ของ macOS เด้งเองเมื่อถึงเวลา ไม่ต้องเปิดหน้าต่างแอปค้างไว้ แต่ตัวแอปต้องทำงานเบื้องหลังอยู่ (ปิดหน้าต่างได้ แต่ไม่ปิดแอป)

**หน้าการแจ้งเตือน**

**ส่วนประกอบ: ตั้ง / แก้การเตือน**
- โน้ตสั้นๆ พร้อมวัน/เวลาเตือน เช่น "ครบ 6 เดือนแล้ว ทบทวนหน่อยว่าเหตุผลที่ซื้อยังจริงอยู่ไหม" (ข้อความอิสระ ไม่มีหมวด)

**ส่วนประกอบ: แจ้งเตือน (Reminders)**
- รายการที่ถึงเวลาแล้ว ทำเครื่องหมายว่าเสร็จได้
- ตัวเลขจำนวนรายการที่ถึงเวลาแล้ว แสดงที่เมนู Reminders ใน Side Bar
- Empty state: ไม่มีรายการค้าง

**ส่วนประกอบ: Task checkbox (อยู่รวมในหน้าแจ้งเตือน)**
- สร้างรายการ task แบบ checkbox ได้ เช่น "อ่านงบไตรมาสล่าสุด" ติ๊กเสร็จได้

**ส่วนประกอบ: ปฏิทิน**
- ปฏิทินรายเดือน
- วันที่มีการเตือนที่ตั้งวัน/เวลาไว้ มีสัญลักษณ์ (แถบหรือจุด) ในช่องของวันนั้น
- กดที่วันเพื่อดูรายการของวัน และทำเครื่องหมายเสร็จได้จากตรงนั้น
- วันนี้มีไฮไลต์ต่างจากวันอื่น และแยกสีรายการที่เสร็จแล้ว/ยังไม่เสร็จ
- Empty state: ไม่มีรายการ

***

## FEATURE 5: ส่งออก CSV

ปุ่ม Export อยู่ 2 จุด (ไม่อยู่ในหน้า Setting)
- หน้าพอร์ต: ส่งออก transaction ของพอร์ตนั้น (รวมปันผล)
- หน้า My Journals: ส่งออกโน้ตทั้งหมด

เงื่อนไข
- ไม่รวมส่วนเครื่องคำนวณเงินเป้าหมาย และไม่รวมพอร์ตที่อยู่ในถังขยะ
- ไฟล์ภาษาไทยต้องเปิดใน Excel แล้วไม่เพี้ยน
- วัตถุประสงค์: ให้ผู้ใช้นำข้อมูลไปคำนวณต่อได้หลากหลาย และใช้เป็นข้อมูลสำรอง

***

## FEATURE 6: รายการหุ้น/กองทุน (ใช้ร่วมกันทั้งแอป)

ไม่ใช่หน้าของตัวเอง เป็นช่องเลือกที่ใช้ใน: หน้าเขียน/แก้โน้ต, หน้าเพิ่ม/แก้ transaction, ช่องค้นหาใน Port log, ฟอร์มเครื่องคำนวณ (โหมดกรอกเอง)
- ผู้ใช้เลือกจากรายการ ไม่พิมพ์ชื่อเอง (เหมือนเว็บลงทุนทั่วไป)
- พิมพ์ค้นหาแล้วเลือก เช่น พิมพ์ "SC" แล้วขึ้น SCB
- ข้อมูลรายชื่อดึงจากแหล่งข้อมูลหุ้น/กองทุนภายนอกที่มีอยู่แล้ว เริ่มจากหุ้นไทย (SET) และหุ้นสหรัฐ
- แต่ละรายการมีอย่างน้อย: ชื่อ, สัญลักษณ์ (ticker), ประเภท (หุ้น/กองทุน), ตลาด

***

## FEATURE 7: บัญชีผู้ใช้และการตั้งค่า

**หน้า: สมัครสมาชิก / ล็อกอิน**
- สมัครสมาชิก (ชื่อ, อีเมล, รหัสผ่าน), ล็อกอิน, ออกจากระบบ
- ข้อมูลทั้งหมดของแอปผูกกับบัญชีผู้ใช้

**หน้า: Setting (หน้าเดียว 3 section)**
1. Account
	- รูปโปรไฟล์
	- ชื่อที่แสดง (แก้ได้)
	- อีเมล (แสดงอย่างเดียว แก้ไม่ได้)
	- ปุ่ม "Save changes" และปุ่ม "Log out"

2. Language & Display
 	- ภาษา: ไทย / English (ทุกหน้าและข้อความในแอปต้องรองรับ 2 ภาษา)
	- เขตเวลา: เลือกเป็นประเทศ (ค่าเริ่มต้น Thailand UTC+07:00) ใช้กับเวลาของการเตือน
	- ปุ่ม "Save preferences"

3. Account Security
	- เปลี่ยนรหัสผ่าน (รหัสผ่านปัจจุบัน, รหัสใหม่, ยืนยันรหัสใหม่)
	- ออกจากระบบทุกอุปกรณ์ (ถามยืนยันก่อน)
	- ลบบัญชี: อยู่ในโซน Danger zone ต้องพิมพ์คำว่า DELETE เพื่อยืนยัน ข้อมูลทั้งหมดถูกลบถาวร

## FEATURE 8: ถังขยะ (Trash)

รวมโน้ตและพอร์ตที่ผู้ใช้ลบไว้ ผู้ใช้เข้ามาเพื่อกู้คืนหรือลบถาวร ไม่มีการลบอัตโนมัติ รายการอยู่ในถังขยะจนกว่าผู้ใช้จะลบเอง

**หน้า: ถังขยะ**
- หัวหน้าแสดงชื่อหน้า คำอธิบายสั้นๆ และจำนวนรายการในถังขยะทั้งหมด
- แบ่งเป็น 2 แท็บ: "Journals (n)" และ "Portfolios (n)" ตัวเลขคือจำนวนรายการในแต่ละแท็บ
* แต่ละแท็บเรียงตามวันที่ลบ ใหม่ไปเก่า
* กล่องข้อความอธิบายว่า รายการในถังขยะไม่แสดงในหน้าอื่นของแอป กู้คืนได้ทุกเมื่อ และลบถาวรแล้วกู้ไม่ได้
* ช่องค้นหาตามชื่อ/หัวข้อ ใช้กับแท็บที่เปิดอยู่

**แท็บ Journals**
- แต่ละรายการแสดง: อารมณ์, หัวข้อ, ข้อความตัวอย่างสั้นๆ, วันที่เขียน, วันที่ลบ
* การ์ดแสดงแบบจางกว่าปกติ ให้รู้ว่าอยู่ในถังขยะ
* กดรายการเพื่ออ่านเนื้อหาเต็มแบบอ่านอย่างเดียว (แก้ไขไม่ได้) ในหน้าต่างนั้นมีปุ่ม "กู้คืน" และ "ลบถาวร"
* ปุ่ม "กู้คืน": โน้ตกลับไปอยู่ในหน้า My Journals ที่ตำแหน่งเดิม (เรียงตามวันที่เขียน) ไม่ต้องถามยืนยัน
* ปุ่ม "ลบถาวร": ต้องถามยืนยันก่อน

**แท็บ Portfolios**
- แต่ละรายการแสดง: ไอคอน, ชื่อ, คำอธิบาย, วันที่ลบ, จำนวน transaction, จำนวนแผนที่บันทึกไว้ซึ่งอ้างอิงพอร์ตนี้
* การ์ดแสดงแบบจางกว่าปกติ และกดเข้าไปหน้าพอร์ตไม่ได้
* transaction ในพอร์ตไม่หายไปตอนอยู่ในถังขยะ
* ปุ่ม "กู้คืน": พอร์ตกลับไปอยู่ในหน้า Portfolio พร้อม transaction ครบ ไม่ต้องถามยืนยัน
* ปุ่ม "ลบถาวร": ต้องถามยืนยันก่อน และบอกผลกระทบเป็นตัวเลข
   - transaction ทั้งหมดของพอร์ตถูกลบถาวร
   - แผนที่บันทึกไว้ซึ่งอ้างอิงพอร์ตนี้ไม่ถูกลบ แต่เปลี่ยนแหล่งที่มาเป็น "กรอกเอง"

**ผลของการอยู่ในถังขยะ**
- โน้ตในถังขยะ: ไม่แสดงในไทม์ไลน์ My Journals ไม่ถูกนับในตัวกรองอารมณ์ ค้นหาไม่เจอ เปิดแก้ไขไม่ได้ และไม่อยู่ใน CSV
- พอร์ตในถังขยะ: ไม่แสดงในรายการพอร์ต ไม่ถูกเลือกในเครื่องคำนวณ และไม่อยู่ใน CSV
- ลบโน้ตจากหน้าเขียน/แก้โน้ต = ย้ายไปถังขยะ แสดงข้อความ "ย้ายไปถังขยะแล้ว" พร้อมปุ่ม "เลิกทำ" และฉบับร่างที่บันทึกอัตโนมัติของโน้ตนั้นถูกลบทิ้งด้วย
- ลบพอร์ตจากหน้า Portfolio = ย้ายไปถังขยะ

**ล้างถังขยะ**
- ปุ่ม "ล้างถังขยะ" ลบถาวรทุกรายการในแท็บที่เปิดอยู่
* ต้องพิมพ์คำว่า DELETE เพื่อยืนยัน และแสดงจำนวนรายการที่จะถูกลบ
* ซ่อนปุ่มเมื่อแท็บนั้นว่าง

**Empty state**
- แยกตามแท็บ: "ยังไม่มีโน้ตในถังขยะ" / "ยังไม่มีพอร์ตในถังขยะ" พร้อมปุ่มพากลับไปหน้า My Journals หรือ Portfolio
