# Functional Specifications: หน้า Transaction Logs & Portfolio Detail (หน้ารายละเอียดพอร์ตและตารางธุรกรรม)

หน้าจอนี้เปิดเข้ามาเมื่อผู้ใช้คลิกปุ่ม **Open** จากหน้า Portfolio เพื่อดูรายละเอียดเชิงลึกภายในพอร์ตเฉพาะเจาะจง ประกอบด้วยการ์ดเป้าหมาย (Goal), การ์ดสรุปสถิติ, ส่วนแสดงหุ้นในพอร์ต (Holdings), และตารางจัดการ Transaction[cite: 5, 6]

## 0. แถบเมนูด้านข้าง (Side Bar Navigation)
แถบเมนูด้านซ้ายสุดของหน้าจอ ทำหน้าที่เป็นศูนย์กลางการนำทางหลักทั่วทั้งแอปพลิเคชัน (แบ่งหมวดหมู่ตามข้อกำหนด Iteration 1) ประกอบด้วย:
* **ส่วนหัว (Logo & App Title):** 
  * โลโก้รูปปลาวาฬและชื่อแอป **Whale Trade Journal**
* **กลุ่ม Main:**
  * **My Journals:** เมนูสำหรับกลับสู่หน้าไทม์ไลน์บันทึกหลัก (สถานะ Active ในหน้าจอขณะนี้)[cite: 2]
  * **Portfolio:** เมนูสำหรับเข้าสู่หน้าพอร์ตการลงทุน[cite: 4]
  * **Reminder:** เมนูสำหรับเข้าสู่หน้าการแจ้งเตือนและปฏิทิน (พร้อมแสดงตัวเลข Badge แจ้งเตือนรายการที่ถึงกำหนด)[cite: 6]
* **กลุ่ม Analytics:**
  * **Saved Plan:** เมนูเข้าสู่ส่วนแผนการลงทุนที่บันทึกไว้[cite: 9]
  * **Target Amount:** เมนูเข้าสู่เครื่องคำนวณเงินเป้าหมาย[cite: 7, 8]
* **กลุ่ม Settings:**
  * **Trash:** เมนูเข้าสู่หน้าถังขยะสำหรับกู้คืนหรือลบพอร์ตถาวร[cite: 4, 5]
  * **Setting:** เมนูเข้าสู่หน้าการตั้งค่าระบบและบัญชีผู้ใช้[cite: 10]
* **ส่วนล่างสุดของ Sidebar (User Profile Card):**
  * แสดงรูปโปรไฟล์ ชื่อผู้ใช้ (เช่น *Thomas W.*) และป้ายสถานะ (เช่น *Dividend Haven*) พร้อมปุ่มลัดสำหรับออกจากระบบ (Log out)[cite: 3]

## 1. ส่วนหัวของหน้าและแถบนำทาง (Header Section & Navigation)
- **ปุ่มย้อนกลับ (Back to Journals / Back to Portfolios):** ปุ่มลูกศรซ้ายสำหรับพาผู้ใช้กลับสู่หน้ารวมพอร์ตหลัก[cite: 5]
- **Breadcrumb / Current Portfolio Pill:** ป้ายแสดงชื่อพอร์ตปัจจุบันที่กำลังเปิดดูอยู่ (เช่น *Long-term passive income portfolio*)[cite: 5]
- **ชื่อพอร์ตหลัก (Portfolio Title):** แสดงชื่อพอร์ตขนาดใหญ่พร้อมไอคอนสถานะ (เช่น *Dividend Sanctuary 🌿*) และไอคอนดินสอสำหรับกดแก้ไขชื่อหรือคำอธิบาย[cite: 5, 6]
- **คำอธิบายพอร์ต (Description):** ข้อความอธิบายสั้นๆ ของพอร์ต (เช่น *Sheltered from market volatility...*)[cite: 5]
- **ปุ่มการทำงานหลัก (Action Buttons ด้านขวาบน):**
  - **ปุ่ม Export CSV:** สำหรับส่งออกข้อมูล transaction ทั้งหมดของพอร์ตนี้ (รวมปันผล) เป็นไฟล์ CSV[cite: 5, 6]
  - **ปุ่ม + Add Transaction:** สำหรับเปิดฟอร์มบันทึกรายการ ซื้อ / ขาย / ปันผล ใหม่[cite: 5, 6]

## 2. การ์ดแสดงผลและสถิติหลัก (Cards Grid Section)

### 2.1 การ์ดเป้าหมายเงินปันผล/เงินต้น (Annual Dividend Goal Card)
- **หัวข้อการ์ด:** *ANNUAL DIVIDEND GOAL* พร้อมปุ่ม *Edit goal* สำหรับปรับแก้ตัวเลขเป้าหมาย[cite: 5]
- **ยอดเป้าหมายหลัก:** แสดงจำนวนเงินเป้าหมายในรูปแบบ THB (เช่น *2,000,000 THB / year* และเปอร์เซ็นต์ความคืบหน้า *40.0% reached*)[cite: 5]
- **Progress Bar:** แถบแสดงสัดส่วนความคืบหน้า พร้อมตัวเลขแสดง Current Yield Run-Rate และ Target[cite: 5]
- **หมายเหตุและแรงบันดาลใจ:** 
  - ข้อความชี้แจง: *"Calculated from recorded transactions & recorded dividends, not market price fluctuations. Your steady cashflow grows undisturbed."*[cite: 5]
  - ป้ายบอกเป้าหมายถัดไป เช่น *✨ Next milestone: 1,000,000 THB (200k to go)*[cite: 5]

### 2.2 การ์ดสรุปยอด DCA สะสม (Total Recorded DCA Card)
- **หัวข้อการ์ด:** *TOTAL RECORDED DCA*[cite: 5]
- **ยอดรวม:** แสดงผลรวมเงินลงทุนตามรายการที่บันทึกทั้งหมด (เช่น *1,450,000 THB*)[cite: 5, 6]
- **รายละเอียดเพิ่มเติม:** ข้อมูลช่วงเวลาการลงทุน (เช่น *Across 36 monthly deposits*) และกราฟเส้นแนวโน้มขนาดเล็กพร้อมช่วงเวลาเริ่มต้น-สิ้นสุด (Nov 2021 - Oct 2024)[cite: 5]

### 2.3 การ์ดอัตราผลตอบแทนเงินปันผล (Avg. Yield on Cost Card)
- **หัวข้อการ์ด:** *AVG. YIELD ON COST*[cite: 5]
- **ตัวเลขเปอร์เซ็นต์:** แสดงอัตราผลตอบแทนเฉลี่ย (เช่น *6.85%* และสถานะ *Steady growing cashflow*)[cite: 5]
- **ข้อมูลเปรียบเทียบ:** เปรียบเทียบกับค่าเฉลี่ยตลาด (เช่น *SET Index avg: ~3.2%* และค่า Spread *+3.65% spread*)[cite: 5]

## 3. ส่วนแสดงรายชื่อหุ้น/กองทุนในพอร์ต (Holdings Section)
- **หัวข้อ:** *HOLDINGS* พร้อมระบุจำนวนหลักทรัพย์ทั้งหมด (เช่น *3 shares*)[cite: 5]
- **รายการ Holdings:** แสดงการ์ดสัญลักษณ์หุ้น/กองทุนแต่ละตัวในพอร์ต (เช่น *SCB* พร้อมจำนวนหุ้น *12,000 shares*) เรียงต่อกันในแนวนอนพร้อมปุ่มเลื่อนซ้าย-ขวา (Pagination arrows)[cite: 5]

## 4. ตารางบันทึกธุรกรรม (Transaction Logs Table)
- **หัวข้อและตัวกรอง:** 
  - ชื่อหัวข้อ *Transaction Logs*[cite: 5]
  - **ช่องค้นหา (Search):** ค้นหาตามชื่อหุ้น/กองทุน เช่น Apple, SCB, TISCO[cite: 5, 6]
  - **ตัวกรองหมวดหมู่/แท็ก:** เช่น *All (3)*, *Banking*, *Energy*[cite: 5]
- **โครงสร้างคอลัมน์ในตาราง:**
  1. **STOCK / FUND:** ชื่อหุ้น/กองทุน, ตลาด/Ticker (เช่น *SCB X Public Co. BKK: SCB • Banking Core*)[cite: 5, 6]
  2. **TYPE:** ประเภทธุรกรรมแสดงด้วยสีและป้ายกำกับชัดเจน เช่น *Dividend* (เขียว), *Sell* (ส้ม), *Buy* (น้ำเงิน)[cite: 5, 6]
  3. **PERCENT UNIT:** อัตราส่วนหรือสัดส่วนต่อหน่วย (เช่น *7.1%*, *6.4%*)[cite: 5]
  4. **DATE:** วันที่ทำรายการ พร้อมรายละเอียดเสริม (เช่น *Oct 2026 Semiannual pay*)[cite: 5, 6]
  5. **AMOUNT:** จำนวนเงินรวมและรายละเอียดต่อเดือน (เช่น *124,000 THB* / *10,333 THB / mo*)[cite: 5, 6]
  6. **ACTION:** ปุ่มเครื่องมือสำหรับ **แก้ไข (Edit)** และ **ลบ (Delete)** รายการธุรกรรม[cite: 5, 6]
- **การจัดกลุ่ม:** แบ่ง section รายการตามรายเดือน (เช่น เรียงจากใหม่ไปเก่า)[cite: 5, 6]
- **Empty State:** หากพอร์ตใหม่ยังไม่มี transaction จะแสดงข้อความแจ้งเตือนสถานะว่าง[cite: 5, 6]
