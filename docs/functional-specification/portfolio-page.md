# Functional Specifications: หน้า Portfolio (หน้ารวมรายการพอร์ต)

หน้าจอนี้ทำหน้าที่เป็นศูนย์กลางของฝั่ง Port สำหรับแสดงรายการพอร์ตการลงทุนทั้งหมดของผู้ใช้ในรูปแบบการ์ด (Portfolio Cards) เพื่อให้เห็นภาพรวมของเป้าหมาย (Goal) และสถิติต่างๆ ของแต่ละพอร์ต[cite: 5, 7]

---

## 0. แถบเมนูด้านข้าง (Side Bar Navigation)
แถบเมนูด้านซ้ายสุดของหน้าจอ ทำหน้าที่เป็นศูนย์กลางการนำทางหลักทั่วทั้งแอปพลิเคชัน (แบ่งหมวดหมู่ตามข้อกำหนด Iteration 1) ประกอบด้วย:
* **ส่วนหัว (Logo & App Title):** 
  * โลโก้รูปปลาวาฬและชื่อแอป **Whale Trade Journal**
* **กลุ่ม Main:**
  * **My Journals:** เมนูสำหรับกลับสู่หน้าไทม์ไลน์บันทึกหลัก (สถานะ Active ในหน้าจอขณะนี้)[cite: 2]
  * **Portfolio:** เมนูสำหรับเข้าสู่หน้าพอร์ตการลงทุน[cite: 4]
  * **Reminder:** เมนูสำหรับเข้าสู่หน้าการแจ้งเตือนและปฏิทิน (พร้อมแสดงตัวเลข Badge แจ้งเตือนรายการที่ถึงกำหนด)[cite: 6]
* **กลุ่ม Analytics:**
  * **Saved Plan:** เมนูเข้าสู่ส่วนแผนการลงทุนที่บันทึกไว้[cite: 9]
  * **Target Amount:** เมนูเข้าสู่เครื่องคำนวณเงินเป้าหมาย[cite: 7, 8]
* **กลุ่ม Settings:**
  * **Trash:** เมนูเข้าสู่หน้าถังขยะสำหรับกู้คืนหรือลบพอร์ตถาวร[cite: 4, 5]
  * **Setting:** เมนูเข้าสู่หน้าการตั้งค่าระบบและบัญชีผู้ใช้[cite: 10]
* **ส่วนล่างสุดของ Sidebar (User Profile Card):**
  * แสดงรูปโปรไฟล์ ชื่อผู้ใช้ (เช่น *Thomas W.*) และป้ายสถานะ (เช่น *Dividend Haven*) พร้อมปุ่มลัดสำหรับออกจากระบบ (Log out)[cite: 3]

## 1. ส่วนหัวของหน้าและแถบเครื่องมือ (Header Section & Tools)
- **สถานะระบบและวันที่ (Top Bar):** แสดงสถานะบรรยากาศตลาด (เช่น *Market quiet*) และวันที่ปัจจุบัน (เช่น *Thursday, Oct 24*)[cite: 4]
- **ชื่อหน้า (Page Title):** หัวข้อหลัก "Your Portfolios 🌿" พร้อมคำอธิบายย่อ *"Each portfolio is its own quiet little garden. Open one whenever you're ready."*[cite: 4]
- **ตัวเลือกมุมมองด่วน (Quick Bar Options):** 
  - **3 portfolios:** แสดงป้ายบอกจำนวนพอร์ตทั้งหมดที่มีอยู่ในปัจจุบัน[cite: 4]
  - **Preview empty slate:** ปุ่มสำหรับเปิดดูจำลองหน้าตา Empty State เมื่อยังไม่มีพอร์ต[cite: 4]
- **ปุ่มการทำงานหลัก (Header Actions):**
  - **ปุ่ม Trash (ถังขยะ):** ปุ่มขอบสีแดงพร้อมไอคอนถังขยะ สำหรับกดเข้าสู่หน้าถังขยะ เพื่อดูพอร์ตที่ถูก Soft Delete[cite: 4, 5]
  - **ปุ่ม + Create Portfolio:** ปุ่มหลักสีฟ้าสำหรับเปิดฟอร์มสร้างพอร์ตใหม่ (ตั้งชื่อพอร์ต + คำอธิบายสั้นๆ + กำหนดเป้าหมาย Goal)[cite: 4, 5]

## 2. การ์ดแสดงรายการพอร์ต (Portfolio Cards Grid)
แสดงรายการพอร์ตทั้งหมดในรูปแบบ Grid Layout โดยแต่ละการ์ดจะมีองค์ประกอบดังนี้:

### 2.1 ส่วนหัวของการ์ด (Card Header)
- **ไอคอนประจำพอร์ต:** ไอคอนสัญลักษณ์ในกรอบทรงหยดน้ำ/วงกลม[cite: 4]
- **ชื่อพอร์ต (Portfolio Name):** ชื่อพอร์ตที่ตั้งไว้ (เช่น *Dividend Sanctuary*, *Rainy Day Nest*, *Quiet Growth*)[cite: 4]
- **คำอธิบายสั้นๆ (Description):** ข้อความอธิบายวัตถุประสงค์พอร์ต (เช่น *Anchor Portfolio*, *Safe Cushion*, *Core Compounding*)[cite: 4, 5]
- **เมนูตัวเลือกเพิ่มเติม (Context Menu - 3 Dots):** ไอคอน 3 จุดที่มุมขวาบน สำหรับเรียกเมนูจัดการ เช่น **แก้ไขชื่อ/คำอธิบาย** หรือ **ลบพอร์ต (Soft Delete)** ย้ายไปยังถังขยะ[cite: 4, 5]

### 2.2 ส่วนเป้าหมายและการคืบหน้า (Annual Goal & Progress)
- **เป้าหมายเงิน (Annual Goal Amount):** แสดงยอดเงินเป้าหมายที่ตั้งไว้ในรูปแบบ THB (เช่น *2,000,000 THB*, *300,000 THB*, *1,000,000 THB*)[cite: 4, 5]
- **Progress Bar:** แถบแสดงสัดส่วนความคืบหน้าของเงินต้นสะสม[cite: 4, 5]
- **ยอดสะสมปัจจุบัน (Reached Amount & Percentage):** 
  - แสดงยอดรวมเงินต้น + DCA ที่บันทึกไว้ เช่น *800,000 reached* พร้อมเปอร์เซ็นต์ *40%*[cite: 4, 5]
  - เมื่อสะสมครบ 100% แถบจะเปลี่ยนสถานะแสดงเป็นป้าย *"100% full"* หรือ *"ถึงเป้าแล้ว"*[cite: 4, 5]

### 2.3 สรุปสถิติภายในพอร์ต (Portfolio Metrics)
- **Total recorded DCA:** แสดงยอดรวมเงินลงทุน DCA ทั้งหมดที่บันทึกไว้ในพอร์ตนั้น (เช่น *1,450,000 THB*, *300,000 THB*, *620,000 THB*)[cite: 4, 5]
- **Transactions:** จำนวนรายการธุรกรรมทั้งหมดที่มีในพอร์ต (เช่น *28 entries*, *19 entries*, *41 entries*)[cite: 4]

### 2.4 ส่วนล่างของการ์ด (Card Footer)
- **Last updated:** แสดงวันที่อัปเดตธุรกรรมล่าสุดของพอร์ตนั้น (เช่น *Last updated Oct 8, 2026*)[cite: 4]
- **ปุ่ม Open >:** ปุ่มสีฟ้าสำหรับกดเข้าสู่หน้ารายละเอียดพอร์ต (Goal Card + Summary + Port Log)[cite: 4, 5]

## 4. เงื่อนไขและกฎการทำงานของระบบ (Business Rules)
1. **การคำนวณ Goal:** ยอดเงินความคืบหน้าใน Progress Bar คำนวณจาก **เงินต้นเริ่มต้น + ผลรวม DCA จริงที่บันทึกใน Transaction** เท่านั้น (ไม่คิดจากมูลค่าตลาด)[cite: 5]
2. **การลบพอร์ต (Soft Delete):** 
   - เมื่อกดลบพอร์ต พอร์ตจะถูกย้ายไปที่หน้า **Trash (ถังขยะ)**[cite: 5]
   - พอร์ตที่ถูก Soft Delete จะไม่ถูกนำไปแสดงในหน้ารวมพอร์ต, ไม่สามารถเลือกในเครื่องคำนวณเงินเป้าหมายได้ และไม่อยู่ในไฟล์ Export CSV[cite: 5]
   - รายการ Transaction ภายในพอร์ตจะไม่สูญหายเมื่อถูก Soft Delete[cite: 5]
3. **Empty State:** ในกรณีที่ยังไม่มีพอร์ตในระบบ จะแสดงภาพประกอบธีมมินิมอล พร้อมป้ายข้อความเชิญชวนให้สร้างพอร์ตแรก[cite: 5]
